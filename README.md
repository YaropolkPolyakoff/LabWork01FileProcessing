# Система покупки билетов в зоопарк (Zoo Ticket Booking System)

Консольное приложение на C# для управления продажей билетов в зоопарк.

## Описание

Приложение представляет собой информационную систему по покупке билетов в зоопарк. Пользователь может просмотреть информацию о животных зоопарка, а также приобрести билеты, после чего формируется подтверждение покупки.

## Функциональные возможности

### Реализованные сценарии (5):

1. **Основной сценарий**: Покупка билетов в зоопарк
   - Создание заказа с выбранными билетами
   - Расчет итоговой стоимости
   - Подтверждение покупки

2. **Вспомогательный сценарий**: Просмотр информации о животных
   - Загрузка данных о животных из файла
   - Отображение информации о каждом животном

3. **Сценарий изменения состояния**: Управление статусами покупки и билетов
   - Pending → Confirmed (подтверждение)
   - Confirmed → Cancelled (отмена)
   - Confirmed → Used (использование)

4. **Сценарий с вычислениями**: Расчет стоимости с учетом скидок и надбавок
   - Скидки по возрасту
   - Групповые скидки
   - Надбавки за выходные дни

5. **Сценарий с отказом**: Обработка ошибочных ситуаций
   - Некорректные входные данные
   - Нарушение бизнес-правил
   - Отсутствие файлов

### Бизнес-правила (8):

1. **Детская скидка**: Дети до 12 лет получают скидку 50%
2. **Студенческая скидка**: Студенты (12-18 лет) получают скидку 30%
3. **Групповая скидка**: При покупке 5+ билетов применяется скидка 20%
4. **Надбавка за выходные**: В субботу и воскресенье действует надбавка +15%
5. **Выходной день**: Зоопарк закрыт по понедельникам - нельзя купить билеты
6. **Ограничение количества**: Максимум 10 билетов за одну покупку
7. **Валидация возраста**: Возраст должен быть от 0 до 120 лет
8. **Типы и цены билетов**:
   - Взрослый (Adult): 500 руб.
   - Детский (Child): 250 руб.
   - Студенческий (Student): 350 руб.
   - Семейный (Family): 1500 руб.

## Предметная модель

### Классы (5):

1. **Animal** - Животное в зоопарке
   - Свойства: Name, Species, Habitat, Description, Age
   - Валидация обязательных полей

2. **Customer** - Покупатель
   - Свойства: Name, Age, Email, Phone
   - Метод: GetCategory() - определение категории для скидок
   - Валидация возраста и обязательных полей

3. **Ticket** - Билет
   - Свойства: Type, BasePrice, PurchaseDate, ValidDate, Status
   - Метод: GetBasePriceByType() - определение цены по типу
   - Валидация цены и дат

4. **Purchase** - Покупка
   - Свойства: Customer, Tickets, TotalAmount, Status, ConfirmationNumber
   - Методы: Confirm(), Cancel(), CanConfirm()
   - Управление состояниями и валидация

5. **Zoo** - Зоопарк
   - Свойства: Name, Animals, OpeningHour, ClosingHour, ClosedDays
   - Методы: IsOpenOnDay(), IsWeekend()
   - Управление расписанием работы

### Сервисы (3):

1. **ZooService** - Основной сервис управления зоопарком
2. **PricingService** - Сервис расчета цен и скидок
3. **ValidationService** - Сервис валидации данных

## Требования

- .NET 6.0 или выше
- Visual Studio 2022 или Visual Studio Code

## Сборка проекта

### Вариант 1: Visual Studio
```
1. Откройте ZooTicketSystem.csproj в Visual Studio
2. Нажмите F5 для сборки и запуска
```

### Вариант 2: Командная строка
```bash
dotnet build
dotnet run -- animals.txt customer.txt purchase.txt
```

## Использование

### Формат запуска
```
ZooTicketSystem.exe <файл_животных> <файл_покупателя> <файл_заказа>
```

### Пример
```
ZooTicketSystem.exe animals.txt customer.txt purchase.txt
```

### Формат входных файлов

**animals.txt** - Информация о животных (разделитель: |)
```
Имя|Вид|Среда обитания|Описание|Возраст
Лев Симба|Panthera leo|Африканская саванна|Король саванны|7
```

**customer.txt** - Информация о покупателе
```
name=Иванов Иван
age=35
email=ivanov@example.com
phone=+7-900-123-45-67
```

**purchase.txt** - Запрос на покупку билетов (по одному типу на строку)
```
Adult
Child
Student
```

### Выходной файл

**purchase_confirmation.txt** - Подтверждение покупки с деталями

## Тестовые сценарии

Проект включает несколько тестовых файлов:

1. **Базовый сценарий**: `animals.txt`, `customer.txt`, `purchase.txt`
2. **Детская скидка**: `customer_child.txt`
3. **Студенческая скидка**: `customer_student.txt`
4. **Групповая покупка**: `purchase_group.txt`
5. **Ошибочные данные**: `customer_invalid.txt`

## Обработка ошибок

Приложение корректно обрабатывает следующие ошибки:

- Отсутствие входных файлов (FileNotFoundException)
- Некорректные данные (ArgumentException)
- Нарушение бизнес-правил (InvalidOperationException)
- Прочие критические ошибки (Exception)

Все ошибки логируются с понятными сообщениями, программа не завершается аварийно.
